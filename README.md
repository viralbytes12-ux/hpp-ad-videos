# HPP ad videos

Finished Halal Pizza Point ad videos only. Each one is already cleared to run as a public Meta ad (music is Pixabay, license proof kept in the private `hpp-ads` repo).

Meta fetches a video by its raw link:
`https://raw.githubusercontent.com/viralbytes12-ux/hpp-ad-videos/main/<date>/<file>.mp4`

Nothing else goes here: no raw footage, no drafts, no customer or business data.
